# elitedesigner — Beautiful Walls. Inspired Living.

Editorial redesign of https://elitedesigner.site/ in plain HTML, CSS and JavaScript (ES modules). No build step.

## Run

Two ways, both supported by `index.html`:

```bash
cd elitedesigner
python3 -m http.server 8080      # or any static server
```

Open http://localhost:8080 — the page loads the ES modules in `js/main.js`.

Or just double-click `index.html`. Browsers block ES modules on `file://` (CORS), so the page detects that and loads `js/app.bundle.js`, a single classic script built from the same sources.

After editing anything in `js/`, rebuild the bundle so the `file://` version stays current:

```bash
node build.js                    # no dependencies, writes js/app.bundle.js
```

## Structure

```
index.html
build.js            bundles js/*.js → js/app.bundle.js (for file:// use)
css/  style.css · animations.css · responsive.css
js/   main.js · data.js · utils.js · navigation.js · animations.js
      gallery.js · filters.js · search.js · modal.js · newsletter.js
      app.bundle.js (generated by build.js — do not edit)
assets/images · assets/thumbnails · assets/icons · assets/fonts
```

`js/data.js` holds all content. `js/utils.js` holds shared helpers.

## Content and images

All 16 curations, their specs, palettes, filter keys, guides and search terms come from the original site's `WALL_DATABASE`.

| Images | Source |
| --- | --- |
| Designs 01–08, both pillar images, three guide images | Retrieved from the original site. Six of them had a mock browser frame baked in, which was cropped out. |
| Designs 09–16 | The original site shipped these with `url('placeholder')` and no photo. Stand-ins were generated from each entry's own image brief and are marked `imageSource: "replacement"` in `data.js`; the viewer labels them "Stand-in image". |

To swap an image, replace the file in `assets/images` and `assets/thumbnails`, or edit `image` / `thumb` in `data.js`.

## Needs configuration

| Item | Where | Current behaviour |
| --- | --- | --- |
| Newsletter | `CONFIG.NEWSLETTER_ENDPOINT` in `js/data.js` | Empty. The form validates and stores the address in the browser only; nothing is sent, and the visitor is told so. |
| Social links | `CONFIG.SOCIAL` in `js/data.js` | Point at the Pinterest and Instagram home pages, not brand profiles. |

## Differences from the original

- **Load more:** the original button only changed its label to "All 88 TV Wall Collections Loaded" without adding anything. Here it reveals the remaining real entries (4, then 8) and says so.
- **Counts:** "88 Curated Portfolios", "74 Reflective Masterworks" and the per-style counts are kept as the original displayed them; the dataset itself has 8 TV walls and 8 mirrors.
- **Search:** matches every word rather than the whole phrase, so the original's own "Wooden slats" suggestion now returns a result.
- **Explore by Style:** filters the Curator Dispatch grid across both TV walls and mirrors.
- **Read Field Note:** the original has no article text, so the note shows the guide's summary and the curations it refers to.
- **Lenis:** `smoothTouch` was renamed `syncTouch` in Lenis 1.1; both are set.

## Keyboard

`⌘K` / `Ctrl+K` or `/` opens search. In the viewer, `←` `→` navigate and `Esc` closes.
